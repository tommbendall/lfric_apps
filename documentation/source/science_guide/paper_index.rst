LFRic Apps Science Guide
=========================

This document is not shown on the website. It exists solely to define the
combined "paper" PDF (``lfric_science_paper.pdf``), built via
``make latexpdf``, which brings together a curated selection of Science
Guide sections into a single document.

Unlike the website navigation (which auto-discovers every section under
``science_guide/`` via a glob toctree), the toctree below is maintained by
hand. Only sections listed here are included in the combined paper. Add a
new line (``<section>/index``) once a section's content is complete and
ready to be included.
